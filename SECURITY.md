# Security Policy

## Reporting a Vulnerability

Please open a `Security Bug Report` on the
[bug tracker](https://github.com/link-society/krouter/issues/new/choose).

## Supported Versions

| Version | Supported |
| --- | --- |
| [1.1.0](https://github.com/link-society/krouter/releases/tag/v1.1.0) | :white_check_mark: |
| [1.0.0](https://github.com/link-society/krouter/releases/tag/v1.0.0) | :x: |
